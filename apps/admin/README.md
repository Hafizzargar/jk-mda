# JK MDA Admin Newsroom

Administrative portal for the JK MDA News Platform.

## Features
- Real-time Autonomous YouTube News Monitoring & Radar
- Multi-channel ingestion (YouTube, RSS, Wire services)
- AI-assisted article drafting, fact extraction, and editorial review
- Configurable publishing pipelines (Manual Approval vs Autonomous Auto-Publish with grace buffers)
- System health monitoring, email notifications, and audit logging
